# Code of conduct

Participants should be respectful, constructive and welcoming. Critique ideas and code, not people. Harassment, discriminatory language, personal attacks, sexualized conduct, doxxing and publishing others' private information are unacceptable.

Maintainers may remove content, reject contributions, restrict participation or ban accounts when needed to protect the community. They should explain decisions where doing so does not expose private information, and apply these standards consistently.

For platform abuse, use GitHub's Report abuse action. To request maintainer intervention, ask for a private reporting channel without posting sensitive personal details in public issues. Maintainers will handle reports discreetly, but this volunteer project cannot promise a response deadline. These standards apply to repository issues, reviews and other project spaces.
