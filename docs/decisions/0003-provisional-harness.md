# 0003: Provisional OpenCode adapter

Initially provisional, confirmed as the Phase 1 adapter 2026-10-12 after the real spike. Implement one OpenCode adapter based on its documented noninteractive JSON runs and OpenAI-compatible provider configuration. Keep a narrow adapter contract so a two-candidate real spike can change the choice cheaply. The owner initially authorized fixture tests, then supplied a local LM Studio endpoint. OpenCode 1.19.0 and Aider 0.86.2 each completed a toy edit with independent verification; details and failed first runs are recorded in docs/spikes/real-harness.md. OpenCode has structured events and reported usage; Aider provides plain CLI output. The real toy gate passes, while broader capability/throughput and full qualification remain pending.

Sources: [CLI](https://opencode.ai/docs/cli/), [providers](https://opencode.ai/docs/providers/), [configuration](https://opencode.ai/docs/config/). Alternative Aider supports [OpenAI-compatible APIs](https://aider.chat/docs/llms/openai-compat.html); both require a real endpoint comparison.
