# 0007: Durable evidence, sampled audits and reproducible evaluation

Accepted 2026-10-12 after the owner requested PR #2 merge (main `079478a`) and authorized Phase 3. Preserve frontier work through authorized Claude Code sessions only, no automatic paid calls, one execution slot, private state outside Git repositories and the non-sandbox trust model. [PHASE3.md](../PHASE3.md) records this wave's approved contracts/addenda.

Use SQLite v4 as authoritative state and append immutable snapshots in the same mutation transaction. Deliver JSONL from an ordered outbox after commit, verify the complete existing prefix, recover only an incomplete unacknowledged tail, and fsync file/directory before acknowledging. This handles complete-write-before-ack crashes without duplicates and preserves committed decisions when delivery fails. Mismatched/missing acknowledged evidence fails closed with visible health; never replace complete evidence or delete SQLite payloads. Legacy backfill is explicitly a current legacy snapshot, not an invented historical timeline. Repeated identical state/tier updates are no-ops to avoid idle-poll evidence growth.

Record admission policy/provenance and observed readiness frontier state. Atomically store owner decisions, optional owner minutes, sampled audits and evidence. Reports distinguish owner acceptance from worker/check success, ordinary tasks from qualification, known/missing usage, requested/executed repair/escalation and historical unknown readiness. Show counts and denominators; percentages require at least 20 observations. Separate local usage from owner-attested frontier planning/review/escalation/audit usage. No inferred costs, zero-filled missing values or savings claim without a baseline.

Select deferred audits once with a configurable Bernoulli rate (default .30) for accepted ordinary checks-only/local work. Keep availability/data-policy holds pending in denominators. The service never launches audit inference; authenticated owner sessions inspect accepted commit objects and submit strict exact-SHA reports. Normal merge/result branch removal is compatible with auditing; edited worker residue is not evidence. Recheck permission after awaited preparation. Immutable audit conclusions append evidence without changing accepted task/decision history; needs-repair/reject is a miss, warnings alone are not.

Publication permission is separate from inference permission and defaults denied. Sanitized export requires an explicit public GitHub URL grant and anonymous fixed-host public visibility verification, with no redirects or account credentials. Use a closed enum/numeric outcome projection for only that repository, synthetic within-export IDs, and no raw code/specs/commands/logs/errors/findings/paths/notes/timestamps/private names. Reviewed manifests may supply strictly validated public metadata matched to actual current/historical bindings. Unknown old reviewer artifacts/harness versions remain null; later configuration cannot certify them. Never auto-publish.

Qualification uses the pinned Apache-2.0 seven-case tool workload and existing harness/independent verifier. Observed paths, direct commands, outputs, error recovery, test failure/edit/pass ordering and realistic multi-round reads authorize capability observations; final claims do not. Explicitly request temperature 0 and concurrency 1, hash the workload, and separately record operator-reported artifact/license/server/hardware/quantization/settings metadata. Missing/mismatched metadata or fixture provenance cannot qualify. Public profiles are tool-workload-only with empty qualified_classes; no automatic coding-class promotion.

Qualification is real execution and needs a durable job before subprocess launch, sharing all worker/reviewer active and uncertain fences. Fsync result file/directories before finalizing. Returned uncertainty, unexpected exceptions and restart preserve an uncertain job and globally pause inference until one owner-stopped reconciliation timestamp is recorded; do not rewrite its outcome or reuse its work. Invalid metadata is rejected before creating a job.

Historical local reviewer reproducibility needs immutable dispatched model/artifact/harness/version snapshots, not current profile lookup. v4 adds nullable fields; v3 history remains unknown. This prevents a sanitized manifest from attaching a false reproducibility claim after profile changes.

Package/community validation and an isolated-home fixture install smoke exercise distribution without service-manager calls, credentials or paid inference. They do not replace live Claude session/marketplace loading, clean-OS onboarding, real accepted ordinary pilot work and complete real qualification metadata. Pre-alpha remains 0.0.0 until release gates are met; no 0.1.0 tag/publication based on fixture success. Phase 4/5, automatic limit detection and broader routing experiments remain later work.
