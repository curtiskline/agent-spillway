# Pilot task set v1

Original Apache-2.0 fixtures for three independent tasks: greeting (mechanical), slug (small-fix), and permission (risky). Each edits one distinct source file and uses a distinct protected check against the same pinned baseline. There are no dependencies, network calls, automatic decisions or provider credentials.

The creator copies public code, checks and LICENSE into a new repository; generated task specifications and manifest remain private alongside it. Local tasks request default review. Risky work holds for an authorized frontier session under default policy. Creating or checking these fixtures neither qualifies a model nor establishes owner acceptance, audit results or frontier savings.

This pilot/tuning set is separate from held-out evaluation tasks and from the seven-case qualification workload. Preserve its version/hash when reporting results; report failed and held outcomes as well as successes.
