# Reproducible profiles

No qualified community profile is published yet. Copy metadata.template.json to a private location, then fill only facts you can substantiate. Null means unknown. Core fields align with sanitized export metadata: public model identifier, exact lowercase SHA256 artifact hash, exact harness/server SemVer, SPDX-like license, configured context tokens, and structured hardware (memoryGiB required; cpuCores, gpuCount and gpuMemoryGiB optional). Optional serverEngine and settings record safe structured owner-reported configuration, not verified server state.

New runs use workload v2, which states the existing exact discovery glob requirement. Retained v1 assets and historical results are not regraded; suite version and content hash distinguish runs. All observed-tool, protected-check and budget gates remain unchanged.

Hardware and settings must describe the actual run. Qualification explicitly requests temperature 0 and concurrency 1; a different or unknown declared temperature cannot qualify. Known serverEngine, quantization, context, exact artifact/license/versions and structured hardware are required. Seed may be explicitly unpinned (null). Metadata is operator-reported; the runner independently binds exact catalog/model, installed harness version and declared artifact identity, and records requested settings separately. It preserves observed tools/checks/usage and never modifies qualified_classes. A real complete seven-case pass can qualify the fixed tool workload only. Coding class acceptance, held-out evidence and audited miss rates require separate evaluation. Fixture or incomplete results cannot become qualified profiles.

Community JSON files under community/ are explicit reviewed projections, never automatic exports. They contain no endpoint IDs/URLs, private catalog bindings, paths, dates, logs or prompts. Run `node scripts/validate-community.mjs` after a build to validate every profile. Its schema requires real provenance, complete reproducible metadata, all seven observed passes and empty qualified_classes. Do not copy a private result file into this directory. Publication/release remains an owner decision.
